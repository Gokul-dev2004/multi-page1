# Multi Page Website

A responsive **multi-page website** designed with a clean and modern user interface. This project demonstrates multiple web pages connected through intuitive navigation with a consistent layout and responsive design.

## 🌐 Live Demo

**[View Live Website](https://gokul-dev2004.github.io/multi-page1/)**

## ✨ Features

* 📄 Multiple web pages
* 📱 Fully responsive design
* 🎨 Clean and modern UI
* 🧭 Easy navigation between pages
* 🖥️ Mobile, tablet, and desktop friendly
* 🌐 Deployed using GitHub Pages

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Git & GitHub
* GitHub Pages

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Gokul-Dev2004/multi-page1.git
```

### 2. Navigate to the project folder

```bash
cd multi-page1
```

### 3. Open the project

Open `index.html` in your browser.
